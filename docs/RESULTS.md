## 故障与成本

TR12 第 1 段原服务已核验终态，原控制器退出根因未知。保留原 raw、attempt、deadline 和保守 28,800 秒成本，没有因等待豁免回写退费。其 951 个终态文件、302 完整 ACK、两个恢复点、全部 RNG、league、cursor、104 pending 已通过完整字节及恢复核验。后续零更新 GPU 验收核对了 127 个 tensor、97 个 optimizer slot 和同卡恢复结果。

当前等待豁免只针对实测且身份绑定的共享资源阻塞。单作业及 GPU/CPU 累计额度扣除这部分；准备、恢复、采样、优化、归档、评测和未知时间仍计入。原始墙钟、等待、净执行分别保留。新 TR12 单训练 raw 为 8 小时净执行，固定24小时安全窗口；旧已签绝对期限不改。实际 CPU 短作业验证了通知补时与最终硬终止。零更新 GPU 验收中已证实等待150.307972秒，原始1246.234秒，净计费1095.926028秒。

历史运行状态不构成本仓库的实时承诺。工程恢复、出错与排障都保留，不因未产生优化量而从预算中消失。

## 优化分支

独立候选位于 `research/framework_optimization/`，未接入 TR12；多环境、FP16/BF16、GradScaler 和向量化开关保持未部署。原 CPU 48 决策微基准由130.35ms至123.79ms（约5%局部下降），8MiB本地发布复制40.71ms、硬链接28.04ms。均不是训练全链路吞吐收益。

TR11 墙钟10172.641秒，已记录采集969.876秒、更新46.016秒，其余9156.749秒（90.013%）原因未知，不能全部归为归档或 GPU 空闲。现用第2段增加阶段计时，段末核验后再据真实耗时选择工程调整。
