## 恢复、故障与效率

源 generation19/20 及 CPU/GPU 完整状态恢复通过，原件保留；严格历史 600 秒持久化间隔未获认证（文件时间代理最大约 2,051.6 秒），不据此认证长期无人值守链路。

第 2 段服务器因归档背压保存退出，本地终态判定未接受该状态而记失败；原失败和成本保留。测得哈希、存储和 ACK 等待开销显著，PPO 前反向主机耗时仅占已测训练进程约 0.84%。没有证明网络或同期 GitHub 上传造成积压。

原第 1 段控制器退出根因仍未知，保守 8 小时计费未回写。等待豁免仅适用于已核实的共享资源阻塞；其他准备、恢复、归档、评测及未知时间继续入账。详见最终报告中的费用快照和原 attempt 摘要。
