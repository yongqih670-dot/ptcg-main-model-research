# 公开材料范围

2026-10-29 起，仅发布精选代码、配置、统计结果及复现材料。完整训练数据和恢复归档的上传已取消，自动重试已禁用；原 GitHub Release 的数据分包及未完成附件已删除。

## 保留

- 训练、采样、评测、完整状态恢复和无损归档的实现代码及测试源码。
- 固定对手、牌组、PPO 参数、种子、协议、模型与输入哈希；它们是来源与配置记录，不是数据载荷。
- H002 确认结果、TR00–TR11 结论、TR11 的统计分析及失败回顾、TR12 原协议、提前停止修订、最终评测与分析、精简 BO3 结局表。
- CPU 依赖锁定文件、环境版本、第三方来源与原有许可。

## 未公开

原始回放、训练轨迹、数据分包、模型权重、完整 checkpoint、optimizer、全部 RNG、league/cursor/pending 恢复状态、环境缓存及 wheels 均不随本精选版本下载。最终受保护评测池也未读取或发布。

TR12 不再续训。本次同步不上传完整训练数据与恢复归档，也不启动对战或优化。公开的 5,650 行结局表只含系列编号、单元、席位、胜平负和运行检查，不含动作、observation、回放或训练轨迹。

这些材料的本地及服务器原件继续保留；完整归档索引、哈希和恢复证据仍由所有者持有。本次只撤回 GitHub 公开材料，不释放原始文件。

## 下载和验证

使用仓库主页的 Code → Download ZIP，或[下载当前精选源码](https://github.com/yongqih670-dot/ptcg-main-model-research/archive/refs/heads/main.zip)。解压后运行：

```powershell
python tools/verify_curated.py
```

该命令仅核对精选文件的大小和 SHA-256，不下载任何训练数据，不加载模型，也不发起训练。旧完整数据 Release 已撤回，不再提供分包下载链接或恢复命令。

历史报告中的原始路径与 SHA-256 作为来源证据保留，部分指向未公开材料；脱敏副本的实际哈希以 `manifests/curated-files.json` 为准。统计结果可查阅，完整数值重放需要所有者保留的原始输入，不能宣称本公开子集独立实现了端到端实验复现。
