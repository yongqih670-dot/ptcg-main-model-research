# TR12 最终评测与分析：用户提前停止终点

结果冻结于 2026-10-29 05:41 UTC。训练按用户决定提前结束，终点为最后提交的 **version15**；协议修订在独立评测前冻结，未按胜率选择中间 checkpoint。当前状态恢复与全部 **5,650 BO3** 评测完成，**整体结论为证据不足，不晋级、不提交**。这不是原训练量目标完成。

## 可靠性、恢复与历史工程偏差

50 BO3 可靠性初检通过。主比较及开发面板均通过完整系列、席位平衡、错误 / 非法动作 / 超时 / 内部随机回退为零的检查。完整评测共 5,650 BO3，其中用于强度统计的是 5,600 BO3；初检得分不参与选模型。

源 generation19/20 两个恢复点均完成 CPU 冷恢复；actor、critic、127 个模型 tensor、97 个优化器状态、Python / NumPy / CPU / CUDA / 采样 RNG、league、cursor、pending 和归档引用得到核验。GPU 新进程恢复结果及 RNG 一致，条件 log-prob 最大误差 1.5778e−5（阈值 1e−4），价值误差 3.0994e−6（阈值 2e−4）；恢复验收没有新采样或优化。复用 477 个源归档 ACK，零更新 GPU 验收核对 92 个 ACK；原件和两个有效恢复点继续保留。

**当前状态字节恢复通过，不等于历史长期无人值守链路已验收。** 断点文件 mtime 代理有 6 个间隔超过 600 秒，最大约 **2,051.6 秒**。mtime 不是精确单调提交时刻，不能据此认证严格 600 秒持久化间隔；配置中的 600 秒触发检查还受完整 BO3、安全点、保存、哈希和归档阻塞影响。本项历史工程偏差保留，不作“已通过保护”的声明。

## 训练健康、效率与停止原因

新增 7 次更新的模型、优化器和梯度均为有限值，首个成功 minibatch 策略梯度 L2 约 2.95–5.07，非零。更新平均 entropy 约 0.37–0.39；loss / value loss 随不同批次波动，没有可据以宣称棋力单调提高的损失趋势。梯度范数记录在配置的 0.5 裁剪之前，不能仅凭较大原始范数认定发散。

version11 在第二 epoch 触发 KL 早停，首 epoch 已完整覆盖；version15 在第一 epoch 末尾 KL 约 0.03214 时停止，53 条未获覆盖已排除。各小批次训练对手 BO3 得分约 35%–60%，既用于反馈又样本较小，只作描述。

第 2 段已计费 13,939.75 秒，即 3.87215 GPU 作业小时；有效新增约 2.370 决策/秒，约 70.33 分钟/每万条。训练进程的独占主机计时如下：

| 阶段 | 秒 | 已测训练进程占比 |
|---|---:|---:|
| 完整文件哈希 | 2,735.8 | 25.41% |
| 归档 ACK 等待 | 1,709.3 | 15.88% |
| PPO 前反向与优化主机耗时 | 89.9 | 0.84% |

归档、哈希和存储开销显著。控制器与训练进程的时钟重叠，包含计时与独占计时也重叠，不能相加；PPO 主机耗时不是 CUDA 内核时间或 GPU 利用率。接收 / 压缩 / 校验是合并计时，未独立隔离网络影响。

已证实服务器在 version15 因归档背压保存退出：当时 79 个待确认对象、542,972,266 字节，超过 512 MiB 边界。本地终态判定器不接受 `checkpointed_archive_backpressure`，因而把已保存的退出记为失败。原失败、费用和截止证据全部保留。没有数据丢失证据；也**没有证明同期 GitHub 上传或网络单独造成了积压**。

## 费用与结论边界

截至结果汇总的 TR12 阶段快照：GPU 作业约 **12.8035 小时**、CPU 作业约 **1.9253 小时**；项目累计约 GPU **35.8264 小时**、CPU **11.9132 小时**。这是报告快照，随后少量本地报告生成与只读核对另有本地账本记录；此次发布不重写研究账本。原第 1 段保守完整 8 小时计费、所有失败与 attempt 保留。只有身份绑定且已核实的共享资源等待扣除，准备、恢复、归档、评测、I/O 等待和无法核实的时间继续入账。

本实验可支持：当前终点可恢复；实际新增量 57,762 条得到去重核验；固定对手有小幅正向信号但未过主门槛；开发面板没有整体提升证据。不能支持：完成原 320,768 新增量目标、对该原定剂量终点的效果结论、未见对手泛化、自动晋级或比赛提交成功。没有独立第二 seed、最终池与部署 / 提交验证。**不再续训，也不新增科学假设。**
